# AutoLoc



\# AutoLoc



Plateforme de gestion de location de véhicules multi-agences.



\## Objectifs du projet

\- Gérer les véhicules, les agences et les réservations

\- Suivre les contrats de location et les paiements

\- Exposer une API REST documentée (Swagger)



\## Acteurs identifiés

\- \*\*Client\*\* : consulte les véhicules, réserve, loue

\- \*\*Agent d'agence\*\* : traite les réservations et les retours

\- \*\*Responsable d'agence\*\* : suit l'activité de son agence

\- \*\*Administrateur\*\* : gère les agences, les utilisateurs et la configuration



\## Stack technique

Java 17, Spring Boot, Maven, MySQL (XAMPP), Git/GitHub, Postman, IntelliJ IDEA
